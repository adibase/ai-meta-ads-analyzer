# AI Meta Ads Analyzer

Experimental AI-based tool for analyzing Meta Ads campaigns and generating actionable insights.

## Features
- Campaign performance analysis (CTR, CPL, conversions)
- Problem detection (weak creatives, broad targeting, inefficient budget allocation)
- Automatic strategic recommendations

## Why this project
I am building automation systems for digital marketing to reduce manual analysis time and improve decision-making.

This project is a base for integrating advanced AI models such as Claude to improve:
- reasoning quality
- insight generation
- campaign interpretation
- decision support

## Status
Working prototype

## Goal
Build an AI-assisted decision system for analyzing and optimizing advertising campaigns.
